# OpenAPI Specification Downgrader

This tool downgrades an OpenAPI specification (OAS) from v3.1.0 to v3.0.3

## Example ##

To downgrade the OAS for the Models API, run the following from the root of the project:
`./manage downgrade-models oas-downgrader`

This will read in the OAS of the Models API and output the downgraded spec to the assets directory
