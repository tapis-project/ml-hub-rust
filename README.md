# MLHub

MLHub helps organizations discover, govern, move, and deploy AI assets. It provides a common place
to work with models, datasets, deployments, and AI agents across platforms and environments.

## Capabilities

- **Model and dataset catalogs** — register, describe, search, and discover reusable AI assets and
  their metadata.
- **Artifact movement** — ingest and publish model artifacts across supported storage, registry,
  and platform integrations.
- **Model deployments** — define and deploy models for inference
- **AI agent discovery** — register and discover agent capabilities through a consistent API.
  GitHub, S3-compatible storage, and Tapis.
- **Automation-friendly interfaces** — use versioned APIs and generated SDKs to integrate MLHub
  into applications and operational workflows.
- **Portable operation** — run MLHub locally or deploy it into Kubernetes-based environments.
